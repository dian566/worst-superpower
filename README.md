An entry for the make.fun bounty **Worst Superpower** — one line, at most 140 characters, inventing the most useless superpower imaginable. See the bounty at [make.fun](https://make.fun).

## The superpower

> I can predict the future, but only events that already happened.

Perfect foresight, zero-day delivery. The future is fully known — the moment it stops being the future.

## Running it

`main.py` is a tiny deterministic program: it validates the line (1–140 characters, non-blank, valid UTF-8) and writes it, byte-identical on every run, to `/output/entry.txt`. No randomness, no clock, no network, no input — only the line.

```sh
python3 main.py
cat /output/entry.txt
```
